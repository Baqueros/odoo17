About
============
Currently, in odoo, there is no feature for restrict product out-of-stock in the point of sale. In this module when you make an order if there is not enough product quantity in stock then it raises a warning, however, the POS user can still place new orders for items that are out of stock or not in stock.

Installation
============
1) Copy module files to addon folder.
2) Restart odoo service (sudo service odoo-server restart).
3) Go to your odoo instance and open apps (make sure to activate debug mode).
4) click on update app list.
5) search module name and hit install button.
